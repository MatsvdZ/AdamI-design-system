AdamI Design System

The full foundation, now: palette, type, layout grid, components and brand rules, all decided in the kickoff. This replaces the earlier draft that was simply extracted from the live site — every value below is a deliberate choice, ready to carry into the Figma component library. Page layouts are the next step, once these foundations are locked.

Status foundations, components & brand rules confirmed Fonts Montserrat + IBM Plex Mono Logos wordmark, icon & full lockup added — see Logo section

How this feeds into Figma

  1. Colors, type, shadow and grid below become Figma variables and text/effect styles — same names, same values, so component and page files stay in sync with this doc.
  2. Buttons, forms, icons, cards and tags are the starting component set — build variants (hover, disabled, dark) from these as a base.
  3. Imagery direction sets the brief for real photography (team) vs. the logo-forward treatment (cases) — hand this section to whoever shoots or sources images.
  4. Logo usage is fixed: wordmark in the desktop nav, icon in the mobile nav, full lockup with tagline in the hero only, plus explicit misuse and co-branding rules — never mix them up.
  5. Voice & tone applies to every piece of copy on the site — briefing for whoever writes page content.

Foundations

Color

Five brand colors, each with one clear job. Navy and Ink carry text and dark grounds, Cobalt is the mid-tone accent for links and secondary actions, Sky is the soft surface behind cards, and Ember is reserved for calls to action — used sparingly so it keeps its punch. Click a swatch to copy its hex.

Why a 6th value: white text on the brand Ember (#C76607) measures ≈3.9:1 contrast — fine for large graphics, short of the 4.5:1 needed for button labels. Ember CTA (#A6560A) is that same hue deepened until white text clears AA (≈5.3:1). Use the brand hex directly everywhere except solid button fills.

Supporting colors

Not brand choices on their own — derived neutrals and two semantic colors that the six above rely on throughout the system (borders, muted text, disabled states, form validation). Every one of these is already a token in the CSS below; they just don't get their own "hero" card above.

Not shown here: Code BG (#0F2050) and Code Text (#DCE8FB) — used only to style the code blocks on this documentation page itself, not part of the site's palette. Still listed in the token export below for completeness.

Foundations

Typography

Montserrat now carries both headings and body copy — Regular (400) for running text, 600/700 for headings and emphasis. IBM Plex Mono steps back to one job: eyebrows and labels, uppercase and letter-spaced, so it still gives the brand its technical edge without competing with body copy for attention.

One line style for UI icons — 24×24 grid, 1.75px stroke, rounded caps and joins, always inheriting text color so they follow whatever ground they sit on. Platform marks are the exception: use each network's own official icon unmodified, at 20–24px, matched to this baseline.

Case studies identify the client by logo, not by photograph — client photography usually isn't available or on-brand anyway. Three surfaces to place a logo on: plain sky, a navy/cobalt mood fill, or straight on ink for a darker section.

Brand mark

Logo

Three lockups, each with a navy version for light grounds and a reversed version for dark grounds. Each has exactly one job — don't swap them.

Wordmark— nav, desktop & tablet
Icon— nav, mobile
Full lockup— hero only, never in nav
Minimum clear space: keep space equal to the icon's own height clear on every side of any lockup — no text, edges or other marks inside that margin.

Don't

The four mistakes that come up most. If none of these apply, the logo is being used correctly.

Stretch or distort the proportions
Recolor outside the navy / reversed pair
Place on a busy or low-contrast background
Shrink below the minimum size (24px mark height)

Co-branding — next to a client logo

On a case card the client's logo leads — bigger, centered. AdamI's icon stays small and quiet in a corner, at reduced opacity, never matching the client mark in size or position.

Brand

Voice & tone

The same precision as the visual system — direct sentences, real numbers, no hype words. If a sentence would work for any AI consultancy, rewrite it until it only works for AdamI.

Say this

"We cut invoice processing from 40 minutes to 4."

Not this

"We leverage cutting-edge AI to revolutionize your workflows."

Say this

"Book a 30-minute call — no deck, just your data."

Not this

"Unlock the power of AI today!"

Tone — confident, precise, a little technical, mirroring the mono eyebrows. Never salesy or exclamation-heavy.
Numbers — always specific and real; ">1500" beats "many."
CTAs — name the actual next step ("Book a call"), never a vague "Learn more."
